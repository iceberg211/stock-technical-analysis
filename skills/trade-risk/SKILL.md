# 交易风险计划

## 目标

把分析器给出的交易前提转换为风险边界。没有已确认战法、逻辑止损或账户约束时，只指出缺失信息，不替分析器补造方向。

## 输入

- 方向与候选战法；
- 条件式入场或实际入场价；
- 结构失效位置和保护性止损；
- 目标区域与管理方式；
- 账户规模、可接受风险、已有相关仓位；
- 市场、合约乘数、最小交易单位、杠杆与事件风险。

## 固定流程

1. 确认战法已经由上游分析器验证；候选未确认时不计算可执行仓位。
2. 确认止损位来自交易逻辑失效，而不是为了满足盈亏比被任意收紧。
3. 读取 `references/risk-contract.md`，计算每单位风险与理论仓位。
4. 按最小交易单位向下取整，并重新计算实际风险。
5. 检查相关持仓、流动性、滑点、跳空和重大事件。
6. 输出正常、降仓或不交易，并列出原因。

## 强制限制

- 不内置通用的 `1%~2%` 默认风险；用户未提供风险预算时只给公式和所需输入。
- 不使用固定 `R:R >= 1.5` 否决所有体系。比较目标空间、成功概率假设和最大损失，并说明假设来源。
- 不移动结构止损来制造更好看的盈亏比；止损过远时减仓或不交易。
- 不把平保、加仓或摊低成本当作必然降低风险的方法。
- 财报、宏观数据或隔夜跳空可能穿越止损时，单独说明尾部风险。
- 不自动下单，不承诺止损一定按指定价格成交。

## 输出

```text
风险结论：正常 / 降仓 / 不交易 / 信息不足
交易前提：已确认 / 候选未确认
入场条件：
逻辑止损：
每单位风险：
风险预算：
理论仓位：
实际仓位：
最大计划损失：
额外风险：
重新计算条件：
```

含交易建议时附加非投资建议声明。
