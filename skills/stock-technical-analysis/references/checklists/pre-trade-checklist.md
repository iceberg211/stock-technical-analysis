# 入场前检查单 (Pre-Trade Checklist)

> **这张清单的作用不是帮你找交易，而是帮你过滤掉不该做的交易。**

7 项检查分为三类，明确区分**一票否决**与**降级处理**，避免类别与规则自相矛盾：

| 类别 | 包含项目 | 规则 |
|------|---------|------|
| **硬否决项** | ③ Setup 匹配、④ 触发信号、⑤ 收益风险关系 | 任何一项 ❌ → 直接不做 |
| **混合项** | ① HTF 方向、② 位置 | 子状态 ❌ 仍属硬否决（不做）；子状态 ⚠️ 按软降级处理（降信心/提醒 `$trade-risk` 评估缩仓） |
| **软降级项** | ⑥ 事件风险、⑦ 否决理由检查 | 子状态 ❌ 仍否决；子状态 ⚠️ 不否决，但须降低信心并提示风险 |

> 入场条件 = 全部 7 项无 ❌（硬否决项全通过且混合项/软降级项未触发否决子状态）

> 对外输出规范：可保留 `ID` 便于内部映射，但必须优先写项目中文名与原因；禁止只写编号（如 `3✅/4⚠️/5✅`）。

---

### ① HTF 方向（🟡 混合项）

| 状态 | 判定 |
|------|------|
| HTF 与交易方向一致 | ✅ |
| HTF 方向冲突（顺势 Playbook） | ❌ 不做 |
| HTF 方向冲突（区间/反转 Playbook，且关键位与触发极清晰） | ⚠️ 逆大势，显著降低信心并交 `$trade-risk` 评估减仓 |
| HTF 震荡/不明 | ⚠️ 降低信心并提示风险 |

---

### ② 位置（🟡 混合项）

| 位置 | 判定 |
|------|------|
| 支撑附近做多 / 阻力附近做空 | ✅ |
| 支撑附近做空 / 阻力附近做多（如强突破或区间边缘例外） | ⚠️ 逆位置，需极强触发并降低信心 |
| 两个关键位中间 | ❌ 等靠近关键位 |

---

### ③ Setup 匹配（🔴 硬否决项）

| 状态 | 判定 |
|------|------|
| 匹配某个 Playbook 且核心条件全满足 | ✅ |
| 匹配但核心条件缺失 | ❌ |
| 不匹配任何 Playbook | ❌ |

---

### ④ 触发信号（🔴 硬否决项）

| 状态 | 判定 |
|------|------|
| 有明确反转 K 线 / 低级别 BOS / 拒绝信号 | ✅ |
| “感觉到位了”但无具体价格行为触发 | ❌ 等触发出现 |
| 触发出现但与 Playbook 不匹配 | ❌ |

---

### ⑤ 收益风险关系（🔴 硬否决项）

R:R = (目标价 - 入场价) ÷ (入场价 - 止损价)

| 情况 | 判定 |
|-----|------|
| 第一目标来自清晰且可到达的结构，潜在收益覆盖计划风险 | ✅ 继续 |
| 目标空间依赖突破但尚未确认 | ⚠️ 等待确认或降低预期 |
| 第一目标位于入场噪声内，或交易成本后没有合理空间 | ❌ 不做 |

记录实际 R:R 作为描述，但不使用跨策略统一的固定门槛；不得为了凑盈亏比把止损移入结构噪声区。只有用户统计或指定策略规则支持时，才使用对应阈值。

---

### ⑥ 事件风险（软降级项）

| 状态 | 判定 |
|------|------|
| 无即将公布的重大事件 | ✅ |
| 有重大事件但距离 > 24h | ⚠️ 降低预期 + 提前设好出场与隔夜/跳空预案 |
| 重大事件即将公布（< 4h） | ❌ 等事件公布后再评估 |

---

### ⑦ 否决理由检查（软降级项）

**入场前强制找出至少 1 条“不做”的理由并评估权重。**

| 否决理由 | 判定 |
|---------|------|
| 有 CHoCH 但无反向 BOS（趋势可能反转） | ⚠️ 降低信心 |
| 跟前一笔一模一样，那笔刚止损 | ❌ 否决 |
| 找不到明确结构瑕疵但存在明显不安/异常告警 | ⚠️ 降低信心 |
| 审视后反对理由权重低、无实质性结构冲突 | ✅ 通过 |

---

## 多项降级与风险交接

- 出现 1 项 `⚠️`：保留条件式计划，但必须降低信心评级并在方案中显式标出风险项。
- 出现 **2 项及以上 `⚠️` 叠加**：原则上直接放弃或退回观察等待，避免在多重不利条件下硬做交易。
- 本检查单**不内置固定百分比仓位或机械连乘折扣**；具体仓位、减仓幅度与尾部风险评估统一交给 `$trade-risk`。
