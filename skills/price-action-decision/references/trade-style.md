# 剥头皮与波段选择

在环境和候选交易确定后，选择持仓方式。该选择回答如何持有，不是新的入场战法。

## 输出值

- `scalp`：只追求附近可达目标，快速获利；
- `swing`：允许正常回调，争取趋势腿或更大目标；
- `mixed`：部分短线获利，部分保留波段；
- `no_trade`：空间、概率、时间或管理能力不支持交易。

## 按环境选择

| 环境和方向 | 默认方式 |
|---|---|
| 强突破顺势 | `swing` 或 `mixed` |
| 窄幅通道顺势 | `swing` 或 `mixed` |
| 宽幅通道顺势 | `swing` 或 `mixed` |
| 宽幅通道逆势 | `scalp` |
| 宽交易区间边缘 | `scalp`，强反转可 `mixed` |
| 窄交易区间 | `no_trade` |
| 高潮后的第一反向交易 | `scalp`，确认新趋势后重新判断 |

## 决定因素

- 最近合理目标离入场有多远；
- 结构止损与目标空间是否匹配；
- 当前运动是趋势本身还是区间中的一条腿；
- 剩余交易时间是否足够；
- 用户是否具备限价、宽止损和加仓所需的管理能力。

## 管理边界

- 剥头皮失败后，不得为了逃避小损失被动改成波段；
- 波段交易不能因普通一根反向 K 线就缩成短线，先检查原趋势前提；
- 趋势中可以先实现部分利润并保留部分仓位，但目标必须来自结构；
- 小目标意味着需要更高成功概率，不能用很远止损追求很小利润；
- 无法明确选择持仓方式时，输出 `no_trade` 或等待。
