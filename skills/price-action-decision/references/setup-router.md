# 交易模式路由

先判断市场环境，再跳转到对应处理方式。这里路由的是**盘面状态**，不是章节号。

## 路由表

| 当前盘面 | 主要模式 | 读取参考 | 核心问题 |
|---|---|---|---|
| 强突破并有跟进 | BO+FT 顺势 | `bo-ft.md` | 突破是否被接受，还是马上失败 |
| 窄幅通道 | 默认顺势；小回调 / H1-H2-L1-L2 / 收盘追单 | `tight-channel.md`、`h2-l2.md`、`late-trend.md` | 逆势方是否还能赚钱 |
| 宽幅通道 | 顺势回调波段；边缘逆势短线 | `broad-channel.md`、`h2-l2.md` | 趋势方向与双向短线如何分层 |
| 交易区间下部 | BLSHS 多头、失败下破 | `trading-range.md`、`bo-ft.md` | 是否有足够空间，是否还在价值区 |
| 交易区间上部 | BLSHS 空头、失败上破 | `trading-range.md`、`bo-ft.md` | 是否有足够空间，是否还在价值区 |
| 交易区间中部 | 等待 | `trading-range.md` | 有没有异常强失败突破或其他明确优势 |
| 原趋势被强烈挑战并再次测试 | MTR 候选 | `mtr.md` | 这是小反转、区间，还是可能的新趋势 |
| 趋势末端高潮且反向跟进 | 高潮反转候选 | `climactic-reversal.md` | 先获利了结、等修正，还是已有真正反转 |
| 趋势仍强但已错过早期入场 | 趋势后段参与 | `late-trend.md` | 现在追随是否仍有正的交易者方程 |
| 开盘初始运动失败 | 开盘反转场景修正 | `open-reversal.md` | 失败是否有跟进，还是只是普通回调 |

## 常见状态转换

```text
强突破
  -> 窄幅通道
  -> 宽幅通道
  -> 交易区间
  -> 新突破
```

这只是常见演化，不是固定顺序。还要处理：

- 突破立即失败并回到旧区间；
- 窄幅通道在一次强反向突破后直接进入区间；
- 宽幅通道恢复成新突破；
- 高潮只造成获利了结和区间，没有形成反向趋势；
- MTR 候选失败，原趋势恢复；
- 低周期已翻转，但高周期仍是原趋势中的一条回调腿。

## 选择规则

1. 先由市场状态排除不合适模式。
2. 再比较位置、方向、信号质量和前方空间。
3. 只输出一个主要模式；只有两种解释都合理且等待条件不同，才保留一个备选。
4. 主要模式和备选必须有不同触发条件，不能同时成立。
5. 没有清晰优势时，输出“不交易/等待”。
6. 若主要模式是反转或逆势，必须额外通过交易者方程过滤。
7. 候选交易保留后读取 `trade-style.md`，确定剥头皮、波段、混合或不交易。

## 冲突处理

- 已发生且有跟进的价格事实，高于对未来的形态预期。
- 强突破或窄幅通道，高于尚未确认的反转形态。
- 区间位置和失败突破，高于区间内部的趋势形态。
- 高潮是环境警告，不等于已确认反转。
- MTR 是反转交易结构，不是独立市场状态。
- 宽幅通道中的区间外形，短线可按区间交易，但波段方向仍优先通道方向。
- 区间中的 H2/L2 只按局部运动处理，不能套用强趋势目标。
- 开盘反转只改变开盘背景权重，不覆盖市场状态。
- Bailout 不参与入场模式竞争。

## 从环境到交易候选

每个主要环境至少检查三个候选，再筛选：

1. 顺当前 Always In 或主要趋势的交易；
2. 仅当环境允许时的逆势价值/反转交易；
3. 等待或不交易。

用位置、跟进、前方空间、逻辑止损、订单方式和交易者方程淘汰不合理候选。最终只保留当前最佳动作。

## 不要错误路由

- H2/L2 是趋势或旗形里的入场结构，不是市场环境；H1/L1 同样属于趋势恢复结构。
- BLSHS 是交易区间的价值交易原则，不是所有横盘的自动信号。
- BO+FT 是突破被市场接受后的处理，不是看到越界就追单。
- MTR 必须先有原趋势、足够反向压力和测试；普通双顶双底不够。
- 高潮后的第一反向交易通常先按短线或向区间转换处理。
- 趋势后段参与必须仍有趋势证据，不能只因为“已经走很远”就反向，也不能只因为 FOMO 就无脑追。
